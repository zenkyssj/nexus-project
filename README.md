## Installation

### Linux / macOS
```bash
curl -L https://github.com/zenkyssj/nexus-project/releases/download/v0.1.0/nexus-linux-x64 -o nexus
chmod +x nexus
sudo mv nexus /usr/local/bin/nexus
nexus init
```

### Windows
Download `nexus-win-x64.exe`, rename to `nexus.exe` and add to your PATH.

No .NET installation required.
